About This Project

CropSense AI is an open-source agricultural AI project that applies deep learning to the challenge of early plant disease identification. It was built to provide accessible, science-backed guidance for smallholder farmers in India and globally.

Technology Stack

🤖 PyTorch MobileNetV2 ⚡ FastAPI 🎨 Vanilla JS + CSS3 🗄️ SQLite 🖼 Pillow / PIL 📊 PlantVillage Dataset

⚠️ Important Advisory Notice

This AI system provides decision-support predictions only. It does not replace expert agronomic or plant pathological diagnosis. Always consult your local Krishi Vigyan Kendra (KVK) or Block Agriculture Officer for serious or widespread crop disease situations.

🌾

PlantVillage Dataset

54,303 labeled leaf images across 38 disease classes from Penn State University.

🎯

Model Architecture

MobileNetV2 with ImageNet pretrained weights, fine-tuned on plant disease data with cosine annealing.

📈

Performance Benchmarks

Achieves ~96.8% test accuracy on PlantVillage laboratory images. Real-world field performance varies based on image quality.
